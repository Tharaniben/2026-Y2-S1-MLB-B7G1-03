# Decision Tree Mushroom Classification

This project contains the individual Decision Tree contribution for the IT2011 final evaluation.

## Run

1. Open `decision_tree_mushroom_project.ipynb` in Jupyter.
2. Select a Python environment with pandas, NumPy, matplotlib, seaborn, and scikit-learn.
3. Run all cells from top to bottom.

The notebook reads `data/agaricus-lepiota.data`, compares Decision Tree variants, performs five-fold grid search, evaluates the selected model on a held-out test set, and writes the final group-comparison row to `outputs/decision_tree_group_summary.csv`.

> Safety: This project is educational. Its predictions must never be used to decide whether a real mushroom is safe to eat.
